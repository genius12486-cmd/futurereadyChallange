  * 서버를 이용할때는 리눅스의 점유율이 높다, 리눅스는 오픈소스라 사용료가 들지않는다, CLI방식으로 메모리를 적게 먹고 신속하게 대응할 수 있다.
* 개발자와 보안 담당자는 왜 깃허브에 코드를 올릴까요?
  * 깃허브에 브런치를 따로 사용하면 팀내에 협업이 용이하다, 히스토리를 통해 오류가 나면 이전 버전으로 돌릴 수 있다.
